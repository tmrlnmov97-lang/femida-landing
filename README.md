# femid.ai — landing

Страница собрана из макета Figma «Home · 1440 · Dark».
Токены совпадают с дизайн-системой: переменная fd-* в Figma = --fd-* в CSS.

- `index.html` — разметка всех секций
- `styles.css` — токены, типографика, компоненты, адаптив 1440 / 1024 / 390

Тёмная тема по умолчанию, светлая переключается кнопкой в шапке и запоминается.
